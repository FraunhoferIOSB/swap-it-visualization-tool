.. _Starting an Execution Engine:

============================
Starting an Execution Engine
============================

To start an Execution Engine, click on the three stripes in the top left corner of the canvas. 
In the opened up side bar click on "Start Order", again on "Start Order" and then choose either "Start Campaign" or "Start single Order". 
The only difference between these two options is the default value of started processes. 
If you chose a default setting you should see something like this:

.. figure:: /images/arguments.png
   :alt: Arguments
   :width: 100%

   **Figure 1:** Arguments to start an Execution Engine

Those are the arguments needed to start `Execution Engines <https://github.com/FlorianDue/swap-it-execution-engine/tree/order_priorization>`_.
If you need further information on a specific argument, have a look in the documentation of `Swap-It-Execution-Engine <https://github.com/FlorianDue/swap-it-execution-engine/tree/order_priorization>`_.
After the Execution Engine started successfully, the colors of resources should start to change.
